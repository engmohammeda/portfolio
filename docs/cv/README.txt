السيرة الذاتية الجاهزة للتنزيل
=============================

الملف: mohammed-albakhity-cv.pdf

• هذا الملف يُنشأ تلقائياً من محتوى الموقع (src/data.ts) عبر:
      npm run assets
  (يشغّل scripts/build-assets.py — يتطلب: pip install pillow qrcode arabic-reshaper python-bidi)

• الصفحة الأولى عربية (RTL) والثانية إنجليزية — جاهزة للإرفاق في طلبات التوظيف.

• زرّ "طباعة / حفظ PDF" في قسم الشهادات يُنتج نسخة محدّثة دائماً من نفس المحتوى
  من المتصفح مباشرة، بدون الحاجة لإعادة التوليد.

• استبدل هذا الملف بنسختك الخاصة متى أردت: احتفظ بنفس الاسم تماماً
  (mohammed-albakhity-cv.pdf) وسيعمل زر التحميل بدون أي تعديل في الكود.
